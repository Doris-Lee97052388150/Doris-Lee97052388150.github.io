关于本站

静态托管：本站由 GitHub Pages 提供，纯静态、无后端。所有页面都是预先构建好的 HTML，浏览器直接打开，不需要服务器。
题库：原首页内容已完整保留，并移到独立子页面 xingce/，功能和链接不变。
网页应用：把 zip 包放进仓库的 _incoming/ 目录，GitHub Actions 会自动解压到 apps/ 下并生成子页面； 也可以在本机运行 node tools/import-zip.mjs 手动导入。
SillyTavern：它是跑在你电脑上的服务，GitHub Pages 无法直接托管，所以这里提供的是一个「入口页」， 用 Cloudflare 隧道把电脑上的服务映射出来，手机点开即可使用。
