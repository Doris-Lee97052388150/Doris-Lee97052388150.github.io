怎么导入新的网页包

  • 方式一（推荐，手机也能做）：把 zip 包上传到仓库的 _incoming/ 目录， GitHub Actions 会自动解压到 apps/ 下并重新部署，几分钟后本页就会出现新应用。
  • 方式二（本机）：在本机仓库目录运行 node tools/import-zip.mjs 你的包.zip， 它会解压并更新 apps/manifest.json，然后提交推送即可。
  • 先在浏览器里检查：打开 导入页，把 zip 拖进去可以直接预览内容、检查是否可用，再决定上传。
