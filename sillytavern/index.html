手动设置地址

隧道的临时地址每次重启都会变。如果电脑上的脚本没能自动同步，把新地址粘贴到这里即可； 这个设置只保存在你当前浏览器里（iPhone 上会一直记住）。

怎么让手机连上（三步）

  1. 电脑上启动 SillyTavern：先让它在 localhost:8000 正常打开。
  2. 启动隧道：双击仓库里的 tools/st-tunnel.ps1，它会自动下载 cloudflared、开启隧道， 并把生成的地址写入本页。也可以手动运行：
    cloudflared tunnel --url http://localhost:8000
  3. 手机上打开本页：点「打开 SillyTavern」即可。地址会自动从 sillytavern/url.json 读取。

为什么这里只是一个「入口页」？

因为本站是 GitHub Pages 静态托管，只能存放 HTML / 图片等静态文件，无法运行程序，也无法反向代理你电脑上的服务。 所以正确做法是：SillyTavern 仍然跑在你的电脑上，用 Cloudflare 隧道把它安全地映射到公网， 本页只负责保存并跳转到那个地址——效果和「映射上来」是一样的，手机上点一下就能用。

安全提示：隧道地址一旦公开，任何人都能访问。请务必在 SillyTavern 的 config.yaml 里 开启 basicAuthMode 并设置用户名密码，不要裸奔。
