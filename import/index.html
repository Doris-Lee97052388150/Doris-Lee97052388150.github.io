这个页面能做什么、不能做什么

    能：在本地检查 zip 结构、统计文件数、找出入口页、预览渲染效果、生成建议的 slug 与 manifest 记录。

    不能：本站是 GitHub Pages 静态托管，没有后端，所以浏览器无法直接把文件写进仓库。
    真正「落地」的动作必须由 GitHub Actions（方式一）或本机脚本（方式二）完成——这就是为什么下面要给你两条路。
