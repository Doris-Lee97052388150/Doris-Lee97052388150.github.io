2019–2026 年国考 + 主要省考/联考的《行测》真题，共 **333 份卷子、38808 道题**，直接在浏览器里做题。

## 怎么用

从首页进「题库总目录」（`真题卷/`），可以按关键词、年份、来源筛选，点「开始做题」即可。

- **右上角倒计时**：默认 120 分钟（国考标准），可在「设置」里改 90 / 120 / 150 或自定义；剩余 25% 变橙、最后 5 分钟红色闪烁，**时间到自动交卷评分**；也可随时「暂停」。
- **一屏连续看多道题**，点选项作答；右侧「答题卡」可跳题，已答显示蓝色。
- **交卷即判分**：总分 /100、正确率、各模块得分与答对率、模块得分率条形图，并逐题展开正确答案、你的选择与官方解析。答题卡绿=对、紫=多选漏选、红=错。
- 作答进度自动存在本机浏览器，关掉页面再打开可继续。
- `真题卷/合集-年份-来源/` 是把同组多套卷打包成一页，右上角可切换。

## 评分规则

按国考行测常规模块分值：政治理论 10、常识判断 10、言语理解与表达 24、数量关系 12、判断推理 28、资料分析 16，合计 100 分；
每个模块的分值在该模块**有效题目**上等比例折算。

- **单选**：选对得满分。
- **多选 / 不定项**（上海、北京等卷特有，共 199 题）：与答案完全一致得满分；所选都是正确项但漏选，按选中比例给部分分（自测辅助，与官方细则可能不同）。
- **缺图题 / 题干被遮挡的题**：页面上单独标注，缺图题不计入总分。

## 数据来源

题目、选项、答案与解析来自公开行测真题题库仓库
[ERRRC/xingcezhenti](https://github.com/ERRRC/xingcezhenti)（2016–2026 国考 + 省考，文件标注来源为 `tiku.db 原始题库`），本地解析后生成静态站点。

已做的机器校验：全库 38808 题的选项与答案零异常；站点内 93589 处图片引用全部命中本地图片文件；抽样满答模拟得分精确 100.0 / 100。

已知瑕疵（页面均有标注）：原卷为**网友回忆版**，个别题面可能与考场原卷有字词差异；极少数题题干被 `******` 遮挡、或解析在题库中残缺；广东卷 13 道判断题题库未收录选项，已按「A 正确 / B 错误」补全并标注。

## 技术说明

- 纯静态站点，无后端、无构建依赖，GitHub Pages 直接托管。
- 图片按内容哈希存放在 `img/`，页面只加载自己需要的图片并由浏览器缓存，因此**首次进入某份卷子约 1–3 MB**，同站其他卷子会复用缓存。
- 根目录的 `.nojekyll` 用于跳过 Jekyll 处理。
